# policy/ — 정책 문서 보관소

프로젝트에 적용되는 정책을 **도메인별 하위 폴더**로 관리한다.

## 도메인 인덱스

| 폴더 | 내용 | 상태 (2026-07-22) |
|---|---|---|
| [inspection/](inspection/) | Visual inspection 판정 정책 — defect 정의, 심각도, 판정 기준 | **수신 대기** |

새 정책 도메인이 생기면 폴더 추가 + 이 표 갱신.

## 공통 파일 규칙 (전 도메인)

- 원본: `YYYY-MM-DD-<출처>-원본.<ext>` — 받은 그대로 보존, 수정 금지
- 정리본: `YYYY-MM-DD-<도메인>-policy-v<N>.md`
- 개정 시 덮어쓰지 말고 v2, v3…로 추가 — 산출물(평가셋/스키마)이 특정 버전에 묶이므로 이력 필수
- 정리본 공통 필수 항목: 정책 출처 / 승인자 / 적용 시점 / 근거 문서 링크
